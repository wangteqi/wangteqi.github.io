# ACT复现记录

## 理论部分

### 研究逻辑

1. 研究背景

    精细双臂操作任务需要高精度控制、接触力协调、双臂协同与视觉闭环反馈，例如插电池、穿扎带、开盖等任务。这类任务传统上通常依赖高端机器人、精确传感器和复杂标定，因此系统成本和部署门槛较高。ACT 论文明确提出的问题是：低成本且不够精密的硬件能否通过学习完成精细操作？

2. 研究问题

    现有模仿学习方法，尤其是单步行为克隆，在高精度长时序任务中存在明显不足。一方面，单步动作预测容易导致误差累积，使机器人逐渐偏离训练数据分布；另一方面，人类示教具有非平稳和非马尔可夫特征，相似观测下可能对应不同动作，增加策略学习难度。ACT 论文把 **compounding errors** 和 **non-stationary / non-Markovian demonstrations** 作为核心挑战。

3. 研究动机

    探索低成本、精度有限的机器人平台是否能够从真实人类示教中学习到稳定的精细双臂操作能力，从而降低精细机器人操作对高端硬件和复杂工程系统的依赖。

4. 研究方法

    ACT 提出 **Action Chunking with Transformers**，不再单步预测动作，而是用 Transformer 一次预测未来一段动作序列，即 action chunk；同时结合 CVAE 建模人类示教中的动作序列多样性，并通过 temporal ensemble 平滑相邻动作块的预测结果，从而降低有效决策时域、缓解误差累积并提高执行稳定性。

ACT：解决低成本精细操作中的长时序模仿学习问题
