# π0的复现记录

## 理论部分

### 研究逻辑

1. 研究背景

    机器人学习的长期目标是构建能够完成多样化真实任务的通用机器人策略，而不是为每个任务、每个机器人、每个场景单独训练策略。视觉语言模型已经具备较强的视觉语义理解能力，这为构建通用视觉—语言—动作模型提供了基础。π0 论文将自身放在 **generalist robot policies / robot foundation models** 的背景下。

2. 研究问题

    现有机器人策略通常受限于特定任务、特定机器人平台和有限数据，难以形成跨任务、跨场景、跨机器人形态的通用控制能力。同时，预训练 VLM 虽然具有互联网规模语义知识，但其原始输出主要是语言 token，不能直接生成机器人所需的高频、连续、精细动作。π0 的核心 gap 是：**如何将 VLM 的语义理解能力转化为真实机器人可执行的连续动作能力**。

3. 研究动机

    探索能否构建一种通用视觉—语言—动作机器人基础模型，使其既继承预训练视觉语言模型的语义理解能力，又能够通过机器人数据学习真实物理交互，从而控制不同机器人完成多样化真实世界任务。

4. 研究方法

    π0 在预训练 VLM 基础上增加独立的 **action expert**，并采用 **flow matching** 生成连续机器人动作，使模型能够输出高频、连续的控制指令。其训练数据覆盖多种机器人平台和多样化任务，包括单臂、双臂和移动操作机器人，从而支持通用控制和下游任务适配。

**π0：解决 VLM 如何变成能输出连续动作的通用机器人策略。**
